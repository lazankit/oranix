# Code of Conduct

Oranix follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- **Be welcoming and respectful** — to newcomers especially. Everyone was new once.
- **Be constructive** — critique code and ideas, never people.
- **No harassment** — no insults, personal attacks, sexualized language or imagery, trolling, or publishing others' private information.
- **Assume good intent**, and accept feedback gracefully.

These rules apply in issues, pull requests, discussions and anywhere you represent the project.

## Reporting

If someone makes you feel unwelcome, report it privately to the maintainer through GitHub: use **Report content** on the comment or issue, or open a [private security advisory](https://github.com/lazankit/oranix/security/advisories/new) if it's sensitive. Reports are handled confidentially. Maintainers may remove comments, lock threads, or block people who don't follow these rules.
